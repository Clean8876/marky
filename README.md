# MARKY

A client-side Markdown viewer and editor. Open a `.md` file, paste text, read it on a quiet reading surface, and edit when you need to. Nothing leaves the browser.

```bash
npm install
npm run dev
```

- **Open `.md`** or drop a file onto the page
- **Paste Markdown** to type directly
- **Edit** for a live preview (split on desktop, tabs on mobile)
- Theme is remembered locally
